## 🔬 Smart MicroLab (Current Major Project)
A compact, AI-powered **portable diagnostic device** designed to measure multiple vital health parameters using a small blood sample.  

The system integrates sensors with an **ESP32 microcontroller** to measure:
- CRP (C-Reactive Protein) via a fluorescence-based assay  
- Hemoglobin  
- Blood glucose  
- Body temperature  
- Oxygen saturation (SpO₂)  
- Heart rate  

Using **photodiodes, fluorescence filters, RGB sensors, and lateral flow strips**, the device quantifies biomarker levels.

A locally trained **machine learning model** predicts CRP values and other health indicators, while a cloud-based LLM provides **natural-language health interpretations**, making diagnostics understandable for users.

The Smart MicroLab aims to provide:
- 🏥 Affordable point-of-care diagnostics  
- 🌍 Accessibility in remote & low-resource environments  
- ⚙️ Rapid and reliable health screening
